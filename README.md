# Minecraft Texture: Bloomheld Bouquet

Bloomheld Bouquet is a Minecraft texture asset featuring crisp, pixel-art flower bouquet artwork, with a 96×32 texture strip and a separate 16×16 inventory icon. It provides the artwork only; it does not include a 3D item model, holding animation, crouch animation, or a complete resource pack.

## Install

1. Convert `assets/textures/individual_flower_bouquet.svg` to a PNG texture, preserving its 96×32 dimensions.
2. Convert `assets/textures/individual_flower_bouquet_inventory.svg` to a 16×16 PNG inventory icon.
3. Add the PNGs to the corresponding texture locations in your Minecraft resource pack.
4. Configure the pack’s item model or texture mapping to use the exported files.

## Use

1. Enable your resource pack in Minecraft.
2. Use the configured item to display the bouquet texture and inventory icon.
3. Adapt the model or mapping to your target Minecraft version and pack setup.
